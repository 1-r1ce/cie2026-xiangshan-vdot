## 三、构建与运行命令

```bash
source /home/rv/work/xs-build-env.sh

# 1) 编译裸机程序（nexus-am）
cd $AM_HOME/apps/hello-xiangshan
make ARCH=riscv64-xs CROSS_COMPILE=riscv64-linux-gnu-
# 产物：build/hello-xiangshan-riscv64-xs.bin（5.7 KB）

# 2) 在香山仿真器上运行
cd $NOOP_HOME
./build/emu --no-diff -i $AM_HOME/apps/hello-xiangshan/build/hello-xiangshan-riscv64-xs.bin \
            -C 1000000 --force-dump-result
```

## 四、关键注意点

1. **不要把 image 复制到 `build/` 目录下运行**：`build/` 会被 `make` 重建清理，容易误删；直接用 `$AM_HOME` 下的产物；
2. **不要加 `-F ready-to-run/copy_and_run.bin`**：该选项走 flash 启动路径，实测会把核卡在 bootrom 的拷贝循环里（20 000 周期只提交 300 条指令，PC 停在 `0x10001312`）；
3. `-b` / `-e` 是日志打印区间（log-begin / log-end），不是内存基址；
4. `--no-diff` 关闭与 NEMU 的逐指令比对，仅用于观察 DUT 自身输出；需要验证功能正确性时应去掉该选项并指定 `--diff <nemu-so>`。
