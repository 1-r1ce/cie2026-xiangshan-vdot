## 二、关键操作记录

```bash
sudo apt update

    libgoogle-perftools-dev numactl libsqlite3-dev libzstd-dev \
    gcc-riscv64-linux-gnu g++-riscv64-linux-gnu open-vm-tools
```

### 2.2 环境变量固化

非交互 shell 不加载 `~/.bashrc`，`env.sh` 也不含 java/clang 的 PATH，故新增：

```bash
/home/rv/work/xs-build-env.sh
```

内容见 `1.1-环境部署验证.md` 第三节。**所有构建脚本首行 `source` 该文件**。

```bash

rm -rf build/rtl build/generated-src build/emu-compile build/emu   # 换 CONFIG 必须清理
```

## 三、遇到的问题与处理

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| 1 | `mill ... exec: java: not found` | GraalVM 只在 `/opt/graalvm-jdk-21/bin`，不在非交互 shell 的 PATH | 固化 `xs-build-env.sh`，并写入 `~/.bashrc` |
| 2 | `ccache: error: Could not find compiler "clang++" in PATH` | LLVM 在 `/usr/local/llvm/bin`，不在 PATH；Verilator 生成的 Makefile 用 `clang++` | 同上，PATH 前置 `/usr/local/llvm/bin` |
| 3 | `make emu CONFIG=MinimalConfig` 秒退 `Nothing to be done` | 换 CONFIG 不触发重新展开，静默复用旧 RTL | 构建前 `rm -rf build/rtl build/generated-src build/emu-compile build/emu` |
| 4 | 带 `-F` 启动时 IPC≈0.01，PC 卡在 `0x10001312` | flash 启动走 bootrom 拷贝循环 | 去掉 `-F`，只 `-i` 从 DRAM 直启（IPC→0.5） |
| 5 | 仿真速度仅 170 周期/秒 | 模型 997 MB + `--assert`/`--x-assign unique`/574 编译单元 + 单线程 + 无 AVX2 | 换 MinimalConfig（3.4×）；详见 `docs/tech/仿真速度问题排查报告.md` |
| 6 | `VEXTRA_FLAGS` 覆盖导致 `%Error-NEEDTIMINGOPT` | 命令行变量覆盖了 `verilator.mk` 里的 `VEXTRA_FLAGS += --no-timing +define+VERILATOR_5` | 传 `VEXTRA_FLAGS` 时必须把被覆盖项显式补回 |
| 7 | 快速版（`--no-assert --x-assign fast`）跑完不退出 | 待查（已排除 `--no-snapshot`、`-X 0`） | 暂用 `timeout` + 日志关键字兜底；主线仍用调试版 |
